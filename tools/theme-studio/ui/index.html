Save to Q2

Put the card in a card reader, or connect the Q2 in USB storage mode. This needs a Q2 Pod firmware with card themes.

Saved

  1. Safely eject the card and put it back in the Q2. If the Q2 is connected by USB, leave USB mode instead.
  2. Wait for “Theme saved” on the Q2.
  3. Restart the Q2 to see your theme.

If “Theme saved” does not appear, your firmware does not support card themes yet. The file on the card does no harm.

Theme removed

Save to Q2

Put the card in a card reader, or connect the Q2 in USB storage mode.

Saved

  1. Safely eject the card and put it back in the Q2. If the Q2 is connected by USB, leave USB mode instead.
  2. On the Q2, while a song is on Now Playing, hold Play/Pause and choose EQ.
  3. Pick this preset. It plays straight away, and stays in the list from then on.

With firmware older than V00I, use Audio settings, EQ, Advanced, Presets, Import from SD /EQ, then Apply changes.

Share this theme
